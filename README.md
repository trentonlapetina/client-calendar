# Client Calendar

A simple appointment calendar for booking clients. It has month, week and day views, a client list with history, overlap warnings, and backups (JSON and .ics).

## Your data stays private
This is a single static page. All appointments and client details are saved **only in the browser you use it in** (localStorage). Nothing is sent to a server, and nothing is stored in this repository.

- Use **Backup → Export JSON** regularly. Clearing browser data erases your calendar.
- Data does not sync between devices. Export on one device and import on another.
